
# 🏥 Hospital Management System

A Hospital Management System developed using **C++ and HTML**, applying fundamental Data Structures concepts to manage hospital operations efficiently.

## 📌 Project Overview

This project provides a simple hospital management system with different modules for managing patients, emergency cases, and treatment records.

## ✨ Features

- **Patient Management:** Manage patient records using Linked Lists.
- **Emergency Room:** Organize emergency cases using Queues.
- **Treatment History:** Manage recent treatment records using Stacks.
- **Priority Management:** Prioritize critical patients using Priority Queues.
- **Web Interface:** HTML forms for patient, emergency, and treatment operations.
- **Backend Integration:** CGI integration with C++ to process form submissions.

## 🛠️ Technologies Used

- C++
- HTML
- Data Structures
- CGI

## 📂 Project Structure

- `hospitalcode.cpp` – Main C++ implementation.
- `hospitalinterface.html` – Web interface.
- `README.md` – Project documentation.

## 🎯 Learning Objectives

- Apply data structures to a real-world application.
- Understand patient record management.
- Implement queues, stacks, linked lists, and priority queues.
- Connect a web interface with a C++ backend.
